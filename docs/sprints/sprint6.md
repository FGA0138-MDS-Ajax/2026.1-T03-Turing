# Sprint 6 — Acessibilidade

**Período:** 24/06 - 02/07/2026  
**Objetivo:** Implementar recursos de acessibilidade para diferentes perfis de usuários.

---

## O que foi feito

### Frontend
- Módulo de acessibilidade com configurações visuais
- Opção de aumento de fonte do sistema
- Configurações de contraste para daltonismo
- Adaptações de interface para autismo com tons mais suaves
- Ajustes visuais gerais da interface

---

## Recursos de acessibilidade

| Recurso | Descrição |
|---------|-----------|
| Tamanho de fonte | Permite aumentar ou diminuir o tamanho da fonte em toda a plataforma |
| Contraste | Modos de alto contraste para melhor legibilidade |
| Daltonismo | Paletas de cores adaptadas para diferentes tipos de daltonismo |
| Autismo | Tons mais suaves e interface menos carregada visualmente |
